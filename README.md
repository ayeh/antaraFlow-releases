# antaraFlow

A small, native Mac app that puts all your messaging services (WhatsApp, Telegram, Mail, Outlook and more) in one window. Each service keeps its own login, and unread counts show on the Dock and menu bar.

This repository only hosts the downloads. The app is notarized by Apple.

## Install

The easiest way is the download page: https://flow.antara.ooo/ (it always shows the newest version).

**Download:** get `antaraFlow-<version>.dmg` from the [latest release](../../releases/latest), open it and drag antaraFlow to Applications.

**Homebrew:**

```sh
brew tap ayeh/antaraflow
brew trust ayeh/antaraflow
brew install --cask antaraflow
```

Newer Homebrew versions ask you to trust a tap before using it; `brew trust` does that for this one only.

## Requirements

macOS 13 (Ventura) or later.

## Updates

antaraFlow checks for new versions itself: Settings › About › Check for updates. Homebrew users can also run `brew upgrade --cask antaraflow`.
